# Pedestrian Light

A compact wearable LED lighting system designed to improve pedestrian visibility at night, especially on poorly lit roads and in areas without public street lighting.

The device is battery-powered and uses an ATtiny85 to control an external LED strip through a single push button. A transistor-based circuit allows the same button to manage both system power and normal user interaction.

The goal is to create a simple, compact, and wearable device that makes pedestrians more visible to approaching vehicles in low-light environments.
